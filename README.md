# Restricciones técnicas (obligatorias)
- Solo HTML, CSS y JavaScript vanilla. Sin frameworks, librerías externas, npm ni paso de build.
- La app debe funcionar abriendo `src/index.html` directamente en el navegador (sin servidor).
- Estructura de archivos:
  - `src/index.html`
  - `src/styles.css`
  - `src/app.js`
- No uses CDNs. Si necesitas íconos, usa SVG inline o emojis.
- Usa `localStorage` si se requiere guardar datos.

# Diseño
- Estilo limpio y moderno: mucho espacio en blanco, esquinas redondeadas, sombras suaves, una sola fuente (system font stack) y una paleta de máximo 3 colores definida con variables CSS (`:root`).
- Mobile-first y responsive: debe verse bien desde 360px hasta pantallas de escritorio (usa flexbox/grid y media queries).
- Soporte para modo claro y oscuro con `prefers-color-scheme`.
- Áreas táctiles de al menos 44px en móvil.
- Accesibilidad básica: HTML semántico, etiquetas en formularios, contraste suficiente y foco visible.

# Calidad del código
- Código ordenado, comentado solo donde aporte valor, con nombres descriptivos.
- Separa responsabilidades: estructura (HTML), estilos (CSS) y lógica (JS).
- Maneja casos límite (campos vacíos, estado sin datos, errores).
